## Goal
A Nuxt 4 single-page app in `web/`, built from the official Nuxt UI starter template, that lists the scenes from `GET /api/scenes` and links to `/scene/<id>`.

## Background
- **Nuxt** is a Vue framework with file-based routing: `app/pages/index.vue` is `/`.
- **SSR is off** (`ssr: false`), because WebGL only exists in the browser and FastAPI serves the built files.
- **In development**, Nuxt's dev server proxies `/api/*` to FastAPI on port 8000, so the page and the API share an origin (no CORS).
- **Nuxt UI** provides the components (`UCard`, `UButton`, …).
- We start from the **official starter template** (GENERATOR) instead of writing config by hand.

## Steps
1. From the repo root: `npm create nuxt@latest web -- -t ui`. VERIFY the command against the docs.
   - If it asks: package manager **npm**, **no** git init, no extra modules.
   - Delete the template's demo content you don't need (keep `app/assets/css/main.css`).
2. `cd web && npm install @sparkjsdev/spark@2.2.0 three && npm install -D @types/three`
3. `nuxt.config.ts`: keep the template's `modules` and `css`, and add:
   ```ts
   ssr: false,
   devtools: { enabled: false },
   nitro: { devProxy: { '/api': { target: 'http://127.0.0.1:8000/api', changeOrigin: true } } },
   ```
4. `app/composables/useApi.ts`:
   ```ts
   export type InitialView = { position: number[]; target: number[]; up: number[]; fov_y_deg: number }
   export type VariantInfo = { variant: string; seeds: number[] }
   export type SceneSummary = { scene_id: string; title: string; num_gaussians: number; asset_url: string;
     metrics_3dgs: Record<string, number | string>; variants: VariantInfo[] }
   export type SceneDetail = SceneSummary & { initial_view: InitialView; mesh_quaternion_xyzw: [number, number, number, number];
     asset: { file: string; format: string; bytes: number }; demo_queries: string[] }
   export function useApi() {
     const getScenes = () => $fetch<SceneSummary[]>('/api/scenes')
     const getScene = (id: string) => $fetch<SceneDetail>(`/api/scenes/${encodeURIComponent(id)}`)
     return { getScenes, getScene }
   }
   ```
5. `app/app.vue`: `<UApp>` containing a simple header (the app name "PromptSplat", `NuxtLink`s to `/` "Scenes" and `/results` "Results") and `<NuxtPage />`.
6. `app/pages/index.vue`:
   - load the scenes on mount;
   - show a responsive grid of `UCard`s with the title, Gaussian count formatted like `1.00 M`, `PSNR 27.1 · SSIM 0.91 · LPIPS 0.12` if present, the number of mask variants, and a `UButton` "Open" → `/scene/<id>`;
   - an **empty state** ("No scenes yet: run the pipeline, or `python scripts/make_fixture_scene.py` on the laptop");
   - an **error state** ("API not reachable: is uvicorn running on :8000?").

## Gotchas
- The laptop has Node 25. If the template complains about the engine version, note it in Findings (Node ≥ 20 is fine).
- Never commit `web/node_modules` or `web/.output` (already gitignored).
