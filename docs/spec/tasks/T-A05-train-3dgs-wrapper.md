## Goal
`python -m pipeline train3dgs --scene <id> [--max-steps N]` trains a 3DGS model with gsplat's MCMC strategy on the split's train images and writes `scenes/<id>/3dgs/`.

## Background
We don't write a trainer; we **wrap** gsplat's `examples/simple_trainer.py` (from our fork, patched in T-A04).
- The `mcmc` subcommand selects the 3DGS-MCMC densification strategy with a fixed Gaussian budget (`cap_max`).
- `normalize_world_space` **must be off**: otherwise gsplat re-centers and rotates the scene, and the saved Gaussians no longer line up with COLMAP cameras or SAGA.
- gsplat's CLI is generated by **tyro**. Boolean options become flags such as `--no-normalize-world-space`, and underscores may appear as dashes. So confirm the spellings from `--help` instead of guessing.

## Interface
```python
def build_command(scene_id: str, cfg: dict, max_steps: int | None = None) -> list[str]: ...
def latest_step_file(folder: Path, pattern: str) -> Path | None: ...   # e.g. ("ckpts", "ckpt_*_rank0.pt"), picks the largest int step
def train(scene_id: str, max_steps: int | None = None, force: bool = False) -> Path: ...  # returns 3dgs/ dir
```

## Steps
1. `build_command`. Every path absolute; `steps = max_steps or cfg["gsplat"]["max_steps"]`.
   ```python
   [sys.executable, "simple_trainer.py", "mcmc",
    "--data_dir", src, "--data_factor", str(g["data_factor"]), "--result_dir", out,
    "--split_file", split_json, "--no-normalize-world-space",
    "--strategy.cap-max", str(g["cap_max"]), "--max_steps", str(steps),
    "--lpips_net", g["lpips_net"], "--save_ply", "--disable_viewer"]
   ```
   If `max_steps` is given (smoke run), add `--eval_steps S --save_steps S --ply_steps S` with S = steps, so the short run still writes a checkpoint, stats and a PLY.
2. `train`:
   - skip if `latest_step_file(3dgs/ckpts, "ckpt_*_rank0.pt")` exists and not `force`;
   - otherwise `run_stage(scene_id, "train_3dgs", cmd, cwd=REPO/"third_party/gsplat/examples")`.
3. CLI: `train3dgs --scene ID [--max-steps N] [--force]`.

## Gotchas
- **Never hardcode** `29999` or `30000`. Always use `latest_step_file`.
- Round 1 of the lab check prints gsplat's `--help`. If any flag name differs, fix `build_command` and write the correct spellings in Findings.

## Tests
- `build_command("figurines", cfg)` contains `mcmc`, `--split_file`, the normalize-off flag, `--strategy.cap-max` followed by `1000000`, and absolute paths.
- With `max_steps=500`, the command contains `--eval_steps 500`.
- `latest_step_file` on a tmp folder with `ckpt_6999_rank0.pt`, `ckpt_29999_rank0.pt` returns the 29999 file; an empty folder returns `None`.

## Findings / Blockers
- Flags checked against the fork source (`third_party/gsplat/examples/simple_trainer.py` @ 297addc, `Config` dataclass): `data_dir`, `data_factor`, `result_dir`, `split_file` (P-GS-1), `normalize_world_space: bool = True`, `max_steps`, `eval_steps`/`save_steps`/`ply_steps: List[int]`, `save_ply`, `disable_viewer`, `lpips_net: Literal["vgg","alex"]`; `MCMCStrategy.cap_max`. The CLI is `tyro.extras.overridable_config_cli` with subcommands `default` and `mcmc`. `benchmarks/mcmc.sh` already uses the underscore forms `--eval_steps`, `--disable_viewer`, `--data_factor` and the dash form `--strategy.cap-max`, so the mixed spellings work.
- VERIFY on lab (round 1): `--no-normalize-world-space` is tyro's generated negative flag for a default-True bool; confirm it shows in `--help`.
- gsplat also saves a ckpt and PLY at `step == max_steps - 1` on its own; the extra `--save_steps/--ply_steps` on smoke runs are harmless. Only `--eval_steps` is really needed there (else no `val_step*.json`).
- ASSUMPTION: `--force` deletes `3dgs/` before retraining (like `ingest --force` deletes `source/`). Otherwise a stale `ckpt_29999` from an older run would beat a new 1999-step smoke run in `latest_step_file`.
- `train` fails early with a clear message if `split.json` is missing (instead of crashing inside gsplat after CUDA start-up).
